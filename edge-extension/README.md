# SJTU 体育场馆预约助手（Edge 扩展）

此版本源于对 ifarewell/jAutoVenue 的完善需求，按当前体育场馆平台页面重新实现，不依赖 Python、Firefox、旧场馆 UUID 列表或验证码识别服务。

## 功能
- 保存场馆、项目、具体日期、开始时间及可选场地偏好。
- 从当前页面读取实际场馆和项目选项；按准确名称定位，拒绝重名和不匹配的控件。
- 定位项目与日期，读取目标时段的场地列表，对页面显示可选的场地描边。
- 时间标签与表格行数、场地列数校验；不再以固定“开始时间减7”的公式盲目索引。
- 开关式页面空位提醒、首次发现已有空位提醒、循环声音和桌面通知。
- 只跟踪你启用提醒时的目标标签；已有空位或从零变为有空位时提醒。
- 提醒基准与最近200条日志保存到扩展本地，支持导出。通知确认后停止声音。
- 浏览器重启后提醒默认暂停，需要在目标标签重新启用，避免标签ID变化造成错误跟踪。

## 安装
1. 在 Edge 打开 edge://extensions，开启开发人员模式。
2. 点击“加载解压缩的扩展”，选择本 README 所在的 edge-extension 文件夹（含 manifest.json）。
3. 固定工具栏上的“SJTU 体育场馆预约助手”。这是独立扩展，不会覆盖签到提醒扩展。
4. 初次安装后，刷新此前已打开的体育场馆平台标签，使页面脚本加载。

## 使用
1. 打开 https://sports.sjtu.edu.cn/pc/#/，在 Edge 手动登录 JAccount。
2. 手动打开希望预约的场馆详情页面，再打开扩展。
3. 点击“读取页面选项”，在场馆、项目输入框中选择或输入完整名称。
4. 填写日期、开始时间；场地名称可留空，或填写页面完整名称，如“场地7”。
5. 点击“保存偏好”。如项目/日期不同，可点击“定位项目和日期”，仅切换页面，不选择场地。
6. 点击“读取并高亮空位”，查看结果与橙色描边。平台数据更新可能有延迟，请自行核对。
7. 如需提醒，勾选“启用空位提醒”，点击“应用提醒设置”。可用“测试提醒”和“已收到”验证通知、停止声音。
8. 场地选择、使用须知确认、提交订单和付款，请在官网自行核对并完成。

## 使用边界
当前官网场馆使用须知第15项明确禁止使用“外挂”或其他手段预约场地，因此此版不复刻原脚本的自动选场、批量预约、提交和钱包付款。
本扩展只做页面读取、偏好记录、用户主动触发的项目/日期定位与高亮，不自动刷新抢位，不请求或逆向内部预约API。
提醒观察的是已加载页面，不代表后台服务器实时查询。若平台不自动更新余位，需要用户手动刷新。Edge退出、电脑休眠或断网期间不可持续检测。
不保存JAccount账号密码，不处理验证码，不读取订单、余额或付款资料；会话使用Edge已有登录。
登录过期、结构不匹配、目标时段未展示、场次加载中时显示原因，停止猜测。
页面高亮并不锁定库存；最后以官网场次、价格、订单与支付结果为准。

## 适配与验证（2026-10-03）
已在用户登录的平台检查霍英东体育中心：项目名称标签、日期tab-YYYY-MM-DD、时间标签、场地列、可选状态类。
在羽毛球页面确认15个时间区间与15个场地列的结构；未选择场地、未提交订单或付款。
通过JavaScript语法、有效/无效日期、项目/日期/场馆不匹配、时段边界、行列一致性和场地过滤测试。
尚未在用户Edge中验证扩展实际加载、通知音频送达及其他场馆的布局；如布局变化，助手会报错，需要适配。

## 更新
仓库的 GitHub Actions 在测试通过后生成 `sjtu-venue-helper-版本号.zip`。登录 GitHub，打开成功的“Extension regression tests”运行，在 Artifacts 下载该文件。解压后选择其中的 `edge-extension` 目录加载，不要直接选择 ZIP。构建产物有保留期限，过期时仍可下载仓库源码安装。

维护者可在仓库根目录运行 `python tools/package_extension.py`，产物位于 `dist/`。脚本检查必需资源，并仅打包扩展文件，不包含历史 Python 配置、登录会话或本地日志。

重新运行安装助手将文件复制到固定目录后，在 Edge 扩展页点击重新加载。
仅包含扩展源码，不包含登录会话、推送密钥或个人数据。
